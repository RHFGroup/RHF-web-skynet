# El sitio en dos idiomas (español e inglés)

29-sep-2026. Decisión de Rafael: **todo el sitio en inglés**, para los inversionistas de fuera (la campaña de Google Ads en inglés lleva a estas páginas). El español sigue siendo el sitio principal y **no cambia**: cada página en español debe salir igual que antes, salvo el selector de idioma y los enlaces `hreflang`.

## Rutas

| Español | Inglés |
|---|---|
| `/` | `/en` |
| `/vender` | `/en/sell` |
| `/asesor` | `/en/advisor` |
| `/inteligencia-de-mercado` | `/en/market-intelligence` |
| `/privacidad` | `/en/privacy` |
| `/terminos` | `/en/terms` |
| `/proyectos/<slug>` | `/en/projects/<slug>` |
| `/inmuebles/<slug>` | `/en/properties/<slug>` |

Las anclas de la home (`#proyectos`, `#contacto`…) son las mismas en los dos idiomas.

`src/i18n/idioma.ts` tiene todo lo del idioma:

- `type Idioma = "es" | "en"`.
- `ruta(idioma, rutaEs)`: la ruta en el idioma pedido, a partir de la ruta en español. **En el código las rutas internas se escriben en español y se pasan por `ruta()`**: `href={ruta(idioma, "/vender")}`. Lo externo (https, mailto, wa.me, archivos) sale igual.
- `equivalentes(pathname)`: las dos versiones de una página (para el selector de idioma).
- `alternos(rutaEs, idioma)`: `canonical` y `languages` para `metadata.alternates`.
- `fechaLarga(iso, idioma)` («25 de junio de 2026» / «June 25, 2026») y `mesYAno(iso, idioma)`.

## Componentes

1. Todo componente con texto recibe `idioma?: Idioma` con valor por defecto `"es"`, y se lo pasa a sus hijos.
2. Los textos van en un diccionario local, arriba del componente:
   ```ts
   const TEXTOS = {
     es: { titulo: "Hablemos de tu próximo proyecto" },
     en: { titulo: "Let's talk about your next home" },
   } satisfies Record<Idioma, Record<string, string>>;
   // …
   const t = TEXTOS[idioma];
   ```
   Si un texto depende de datos, una función: `plural: (n: number) => …`.
3. **El español no cambia ni una coma.** Se copia tal cual al diccionario. Es la prueba de que no se rompió nada: el HTML de las páginas en español debe salir idéntico.
4. Los atributos también se traducen: `alt`, `aria-label`, `title`, `placeholder`, mensajes de error y de éxito, el texto de WhatsApp.
5. Los componentes de cliente reciben `idioma` como prop (es un texto: se serializa sin problema). Los que viven en el layout raíz (chat, aviso de cookies, referencia en dólares) no reciben prop: leen `document.documentElement.lang`, que en `/en` vale `"en"` antes de pintar.

## Datos

Los números, precios, fechas, fuentes, URLs, coordenadas y fotos viven **una sola vez**, en `src/data/*.ts`. El inglés solo trae texto.

- `src/data/en/<módulo>.ts` arma la versión en inglés de cada módulo encima del español (copia los objetos y reemplaza solo los campos de texto).
- `src/i18n/datos.ts` devuelve el módulo en el idioma pedido, con los mismos nombres:
  ```ts
  import { noticias, proyectos, zona } from "@/i18n/datos";
  const { NOTICIAS, TEMAS, fechaNoticia } = noticias(idioma);
  ```
  Funciones: `proyectos`, `inmuebles`, `noticias`, `zona`, `proceso`, `asesor`, `desarrolladores`, `resenas`, `reels`, `redes`. Los tipos se siguen importando de `src/data/*.ts`.
- `src/lib/ficha.ts`: `fichaDe(p, idioma)`, `fichaDeInmueble(i, idioma)`, `proyectosEnOrden(idioma)`, `dondeQueda(p, idioma)`, `pinDelMapa(p, idioma)`, `precioDe(p, idioma)` y `areaDe(p, idioma)`, todas con `idioma = "es"` por defecto.

## Reglas que no cambian con el idioma

- **Precio:** el oficial es en pesos colombianos (Ley 1480, art. 26). En inglés se escribe `COP 311,500,000` (nunca `$311,500,000`: en inglés `$` se lee como dólares) y la referencia en dólares sale por defecto con el botón USD, siempre como «≈ US$… reference».
- Cada precio va con su fecha de corte: «Price as of June 25, 2026». Sin fecha, no hay precio: «Price on request».
- Las fuentes y las fechas de cada dato se muestran igual que en español.
- Nada de promesas: ni «best», ni «guaranteed», ni «appreciation», ni «return» como hecho (Ley 1480, arts. 29 y 30).
- Para el propietario: «price estimate based on market comparables». **Nunca «appraisal»**: avaluar exige estar inscrito en el RAA (Ley 1673 de 2013).
- Las etiquetas de área son literales de la fuente: en inglés se traduce la etiqueta y el original va entre paréntesis la primera vez, por ejemplo «Private built area (área privada construida)».
- Las páginas legales en inglés dicen arriba que son una traducción de cortesía y que prevalece la versión en español.

## Cómo se verifica

1. `npx tsc --noEmit` sin errores.
2. `next build` y comparar el HTML de las páginas en español con el de master: solo cambian el selector de idioma y los `hreflang`.
3. Recorrer `/en`: ningún texto en español a la vista (salvo nombres propios y citas de fuentes), enlaces internos dentro de `/en`, 0 rotos, accesibilidad 100.
